# 🧠 ENT (Backend)

Бэкенд-сервис для платформы подготовки к ЕНТ (Единому национальному тестированию в Казахстане). Проект представляет собой полноценную обучающую систему с генерацией тестов, управлением предметами и темами, отслеживанием прогресса и умной аналитикой успешности учеников.

---

## 🛠 Технологический стек

* **Язык:** Java 21+ (поддерживает работу на современных версиях)
* **Фреймворк:** Spring Boot
* **Персистентность:** Spring Data JPA, Hibernate
* **База данных:** PostgreSQL
* **Валидация:** Jakarta Validation (Hibernate Validator)
* **Утилиты:** Lombok, UUID-токены
* **Сборщик:** Maven

---

## 📂 Структура базы данных и основные сущности

* **`User`** - профиль пользователя, аутентификация по кастомным UUID-токенам и хеширование паролей через BCrypt.
* **`Subject`** - предметы ЕНТ, разделенные на категории (`COMPULSORY` — обязательные, `PROFILE` — профильные).
* **`Topic`** - вложенные темы внутри предметов.
* **`Question` & `Option**` - банк вопросов с поддержкой различных уровней сложности (`EASY`, `MEDIUM`, `HARD`) и вариантов ответов.
* **`TestAttempt` & `UserAnswer**` - сессии тестирования и фиксация ответов пользователей в реальном времени.
* **`UserTopicStats`** - агрегированная статистика по каждой теме (количество решенных, процент успешности, цели по баллам `scoreGoal`).
* **`MarkedQuestion`** - избранные/закладочные вопросы для повторения.

---

## 🚀 Основные возможности

1. **Система тестирования:**
* Создание гибких тестовых сессий с выбором нескольких тем (мультивыбор) и фильтрацией по уровню сложности.
* Поштучная отправка ответов с мгновенной проверкой правильности.
* Завершение теста с автоматическим подсчетом результатов и пересчетом процента успешности (`Success Rate`).


2. **Аналитика и Дашборд:**
* Отслеживание прогресса ученика в разрезе тем.
* Установка целевых баллов (`Target Score`) для подготовки к экзамену.


3. **Каталог предметов:**
* Древовидная структура «Предметы -> Темы» с динамическим подсчетом общего количества вопросов.

## ⚙️ Быстрый старт и установка

### 1. Требования

* Установленная **Java 21** или выше.
* Запущенная СУБД **PostgreSQL**.

### 2. Настройка конфигурации

Создайте или отредактируйте файл `src/main/resources/application.properties`, указав параметры подключения к вашей базе данных:

```properties
spring.application.name=ent
spring.sql.init.mode=always
spring.jpa.defer-datasource-initialization=true
spring.datasource.url=jdbc:postgresql://localhost:5432/ent
spring.datasource.username=postgres
spring.datasource.password=12345
spring.datasource.driver-class-name=org.postgresql.Driver

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true

spring.ai.google.genai.api-key=ВАШ_API_КЛЮЧ
spring.ai.google.genai.chat.options.model=gemini-1.5-flash

```

### 3. Запуск приложения

Склонируйте репозиторий и запустите проект через ваш любимый IDE (IntelliJ IDEA) или с помощью Maven:

```bash
mvn spring-boot:run

```

При первом запуске автоматически поднимутся таблицы в базе данных PostgreSQL. Для быстрого наполнения тестовыми данными (предметы ЕНТ, темы, вопросы и пользователи) можно использовать готовые SQL-скрипты миграции/мокинга.
