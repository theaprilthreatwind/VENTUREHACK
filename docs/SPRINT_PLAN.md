## 1. Мини-контракт (фиксируем 10:00–10:30, владелец BE_1)

| Метод (`@/shared/api`) | Запрос | Ответ |
|---|---|---|
| `startPractice` | userId, topicIds, questionsCount, difficulties | `{ attemptId, questions: [{ id, title, type, difficulty, options: [{ id, text }] }] }` |
| `saveAnswer` | attemptId, questionId, optionId | `{ correct: boolean, explanation?: string }` |
| `finishPractice` | attemptId | `{ totalQuestions, correctAnswers, startedAt, finishedAt }` |
| `getDashboardStats` (новый) | userId | `[{ subjectTitle, topicTitle, solved, correct, successRate }]` |
| `login` | email, password | `{ id, username, email, token }` |

- Фронт сохраняет сессию в localStorage `entuz_session` (`{ attemptId, questions, startedAt }`), итог finish — в `entuz_last_result`.
- Экран вопроса — существующий `/practice/question`; результат — новый `/practice/result`. Роутинг `session/[attemptId]` сегодня не трогаем.
- Backend уже отдаёт `start` и `finish` в этом формате; доделываем `saveAnswer`, `login`, `getDashboardStats` (см. задачи).

## 4. Чек-лист демо (5–7 минут)

1. Поднять backend (`mvn spring-boot:run`) и фронт (`npm run dev`), БД наполнена `seed.sql`.
2. Вход тестовым пользователем из сида.
3. Конструктор: выбрать темы, 10 вопросов → старт.
4. Ответить на 2–3 вопроса — показать вердикт и пояснение.
5. Завершить → результат (X/Y, %).
6. Дашборд: цифры по темам обновились.
7. Если real не стабилен — тот же прогон на `npm run dev:mock` (D-07).
